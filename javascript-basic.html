JavaScript Cơ Bản

Hướng dẫn chi tiết về cú pháp, giá trị, biến, kiểu dữ liệu, let/const/var, toán tử và ví dụ thực tế trong JavaScript.

1. Cú pháp JavaScript (Syntax)

Cú pháp là quy tắc viết mã. JavaScript dùng cho web, cú pháp đơn giản, dễ học.

  • Mỗi câu lệnh thường kết thúc bằng dấu ; (có thể bỏ qua nhưng nên dùng).
  • Chú thích một dòng: // Đây là chú thích
  • Chú thích nhiều dòng: /* Đây là chú thích nhiều dòng */
  • JavaScript phân biệt chữ hoa và chữ thường.
  • Biến, hàm, từ khóa phải viết đúng quy tắc.
// In ra "Hello World" trên console console.log("Hello World");
Thực tế: Khi bạn mở trang này, hãy nhấn F12 để mở Console và xem kết quả các ví dụ.

2. Giá trị (Value)

Giá trị là dữ liệu mà biến hoặc biểu thức lưu trữ. Có thể là số, chuỗi, boolean, v.v.

  • Number: 42, 3.14
  • String: "Xin chào", 'Hello'
  • Boolean: true, false
  • null: null
  • undefined: undefined
42 // Number - số
"Xin chào" // String - chuỗi
true // boolean
null // giá trị rỗng
undefined // chưa xác định
Lưu ý: Chuỗi có thể dùng dấu nháy đơn hoặc nháy kép. Số có thể là số nguyên hoặc số thực.

3. Biến (Variable)

Biến dùng để lưu trữ giá trị. Có 3 cách khai báo biến: var, let, const.

  • var: kiểu cũ, có thể khai báo lại, có thể "hoisting".
  • let: hiện đại, chỉ dùng trong block, không khai báo lại trong cùng phạm vi.
  • const: hằng số, không thể gán lại giá trị.
var x = 10; // biến kiểu cũ, có thể thay đổi
let y = 20; // biến hiện đại, có thể thay đổi
const PI = 3.14; // hằng số, không thể thay đổi
Ví dụ thực tế: Dùng biến để lưu trữ thông tin người dùng, điểm số, trạng thái, v.v.

4. Kiểu dữ liệu (Data Types)

JavaScript có nhiều kiểu dữ liệu:

  • Number: Số (10, 3.14)
  • String: Chuỗi ("Hello")
  • Boolean: Đúng/Sai (true/false)
  • Null: Không có giá trị
  • Undefined: Chưa xác định
  • Object: Đối tượng (ví dụ: {name: "An", age: 18})
  • Array: Mảng (ví dụ: [8, 9, 10])
let age = 18; // Number
let name = "An"; // String
let isStudent = true; // Boolean
let address = null; // Null
let phone; // Undefined
let person = {name: "An", age: 18}; // Object
let scores = [8, 9, 10]; // Array
Thực tế: Dùng object để lưu thông tin phức tạp, array để lưu danh sách.

5. let, const, var

  • var: Khai báo biến kiểu cũ, có thể bị "hoisting" (được đưa lên đầu phạm vi).
  • let: Khai báo biến hiện đại, chỉ dùng trong block, an toàn hơn var.
  • const: Khai báo hằng số, không thể gán lại giá trị, dùng cho giá trị cố định.

Khuyến nghị: Nên dùng let và const thay cho var để tránh lỗi.

var a = 1;
let b = 2;
const c = 3;
a = 5; // có thể thay đổi
b = 6; // có thể thay đổi
// c = 7; // lỗi: không thể thay đổi giá trị của const

6. Toán tử (Operators)

  • Toán tử số học: +, -, *, /, %
  • Toán tử so sánh: ==, ===, !=, !==, >, <, >=, <=
  • Toán tử logic: &&, ||, !
  • Toán tử gán: =, +=, -=, *=, /=

Lưu ý: === so sánh cả giá trị và kiểu dữ liệu, == chỉ so sánh giá trị.

let x = 5;
let y = 2;
let sum = x + y; // 7
let isEqual = x == y; // false
let isStrict = x === y; // false
let isGreater = x > y; // true
let isOk = (x > 0) && (y > 0); // true

7. Thực hành: In ra giá trị

Dùng console.log() để in ra giá trị trong JavaScript. Hãy thử thay đổi giá trị biến và quan sát kết quả trên Console.

let name = "An"; let age = 18; console.log("Tên:", name); console.log("Tuổi:", age);

10. DOM Manipulate (Tương tác với DOM)

DOM (Document Object Model) là mô hình tài liệu HTML dưới dạng đối tượng JavaScript. Bạn có thể dùng JS để thay đổi, thêm, xóa, hoặc thao tác với các phần tử trên trang web.

  • Truy cập phần tử: document.getElementById('id'), document.querySelector('.class')
  • Thay đổi nội dung: element.textContent = 'Nội dung mới'
  • Thay đổi style: element.style.color = 'red'
  • Thêm/xóa class: element.classList.add('active'), element.classList.remove('active')
  • Tạo mới phần tử: document.createElement('div')
  • Thêm vào DOM: parent.appendChild(child)
// Ví dụ: Thay đổi nội dung và màu chữ của một phần tử var demoDom = document.getElementById('domDemo');
demoDom.textContent = 'Nội dung đã thay đổi bằng JavaScript!';
demoDom.style.color = 'red';
